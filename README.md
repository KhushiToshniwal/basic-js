# 🧩 Basic JavaScript Projects

This repository contains 4 beginner-friendly JavaScript projects created to practice core JavaScript concepts like DOM manipulation, events, and logic building.

---

## 📌 Projects Included

### 1️⃣ Color Scheme Switcher
- Click on a color box to change the background color
- Uses event listeners and DOM manipulation

### 2️⃣ BMI Calculator
- Calculates Body Mass Index based on height and weight
- Displays health category (Underweight, Normal, Overweight, etc.)

### 3️⃣ Digital Clock
- Displays real-time digital clock
- Uses `setInterval` and JavaScript Date object

### 4️⃣ Guess the Number Game
- User guesses a random number
- Provides feedback (Too high / Too low)
- Limited attempts logic

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript (Vanilla JS)
